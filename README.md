# Josh's AI Agent Skills

A snapshot of the AI agent skills installed on my device, kept here so they can be installed on other machines and AI servers.

## Install

Install interactively with [skills.sh](https://skills.sh):

```bash
npx skills@latest add Joshf225/skills
```

Or clone the repository and copy the skills into the shared agent-skills directory:

```bash
git clone https://github.com/Joshf225/skills.git
mkdir -p ~/.agents/skills
cp -R skills/. ~/.agents/skills/
```
